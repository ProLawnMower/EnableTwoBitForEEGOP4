EEGO P4 显示模式一键切换

通过浏览器 WebUSB 直连设备 ADB，无需安装任何软件 · 项目 EnableTwoBitForEEGOP4

未连接
选择显示模式（切换后翻一页即可看到效果）：
首次使用
  1. 点击「连接设备」，在弹出的设备选择器中选中你的阅读器（勾选"记住此设备"可跳过下次选择）
  2. 阅读器屏幕会弹出「允许 USB 调试吗？」——勾选「一律允许使用这台计算机进行调试」并点允许（浏览器密钥保存在本地，之后访问不再弹窗）
  3. 点任意模式按钮即完成切换

要求：Chrome / Edge 浏览器（桌面版无需装 adb；也可用另一台安卓手机 + OTG 线的 Chrome 打开本页）。若电脑上 adb 正在占用设备，请先断开。

日志
原理：页面通过 WebUSB 与设备的 adbd 直接完成 ADB RSA 握手（webadb.js，密钥存于浏览器 IndexedDB），然后执行 setprop。仅设置系统属性，不触碰任何数据。
